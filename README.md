# Ainul Lore Vault

Build a dark fantasy lore archive website called Ainul Archive.

The site is a searchable encyclopedia for an original universe.

Design:

- Dark gothic aesthetic

- Black background

- Purple accents

- Elegant fantasy typography

- Responsive desktop and mobile layout

Pages:

- Home

- Fragments

- Fusions

- Seven Thrones

- Ainul

- Beast

- Timeline

- AMA Archive

- FAQ

- Power Scaling

Data Structure:

- JSON driven

- Character pages generated automatically from JSON entries

- Search bar across all lore

- Tag filtering

- Relationship links between characters

- Automatic navigation breadcrumbs

Characters contain:

- Name

- Title

- Aspect

- Description

- Abilities

- Combat Attributes

- Relationships

- Image

- Tags

The site should behave like a fandom wiki combined with a modern encyclopedia.
